チャンネル分析収集ツール

プライバシーポリシー

最終更新日：2026年10月3日

1. 利用目的と取得情報

本ツールは YouTube API Services を利用し、運用者本人のチャンネル分析のため、チャンネル・動画の基本情報と集計された分析データを取得します。

対象には ID、名称、動画タイトル、公開日時、長さ、公開状態、再生数、視聴時間、平均視聴時間・平均再生率、登録者の増減、流入元、取得可能なインプレッション・クリック率が含まれます。

2. アクセス権限

使用する権限は youtube.readonly と yt-analytics.readonly です。動画の投稿・編集・削除や収益情報の取得は行いません。Google アカウントのパスワードは収集しません。

3. 処理と保存先

Google の認証・API サービスと GitHub Actions を利用します。取得データは、設定された非公開 GitHub リポジトリの Actions 成果物に CSV、SQLite、ZIP 等で保存します。閲覧範囲は GitHub 側のアクセス権に従います。広告サービスや外部 AI API への送信処理はありません。

更新トークン等の認証情報は GitHub Actions Secrets で管理する構成です。認証情報を分析成果物へ含めないよう設計しています。

4. 保存期間

Actions 成果物の保持期間は 14 日に設定しています。次回収集時には、一時作業用の履歴から 14 日以上前の取得記録を除外します。過去の成果物にも履歴が含まれるため、同じ取得データが約 28 日間残る場合があります。

ダウンロードしたコピーは別途管理が必要です。利用停止・連携解除時には、次項の削除期限を優先します。

5. アクセス取消とデータ削除

アクセス許可は Google アカウントの接続管理から取り消せます。取り消しても、保存済みの成果物は直ちに自動削除されません。

本ツールは運用者本人専用です。利用をやめる、または Google の連携を解除するときは、運用者が収集を停止し、GitHub Actions の全収集成果物、保存済み履歴、管理下の手元のコピーを、利用停止または連携解除から 7 日以内に手動で削除します。

保存データの削除については、下記の問い合わせ先へご連絡ください。本ツール側のデータを削除しても、YouTube 上の動画やデータは削除されません。

6. この説明サイトへのアクセス

この説明サイトは GitHub Pages で配信しています。GitHub はセキュリティ目的で訪問者の IP アドレスを記録します。詳細は GitHub Pages の説明とGitHub のプライバシーに関する声明をご確認ください。

このサイト自体には、アクセス解析・広告・Cookie を設定するスクリプトや、入力フォームを設置していません。
