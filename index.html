チャンネル分析収集ツール
概要プライバシー

本人専用・読み取り専用

チャンネルの実績を、
確かめられるデータに。

「チャンネル分析収集ツール」は、運用者本人の YouTube チャンネルの動画情報と視聴実績を取得・整理する個人用ツールです。YouTube API Services を利用します。

現在は初期設定中です。一般利用者の登録は受け付けていません。

取得・整理する情報

現在の設定では、最新 20 本の動画について直近 28 日間の再生数、視聴時間、登録者の増減、流入元などを CSV で確認できます。

インプレッションとクリック率は、利用可能な既存レポートがある場合に取得します。

読み取り専用

動画の投稿・編集・削除や、収益情報の取得は行いません。

非公開で処理・保存

取得結果は、非公開 GitHub リポジトリの Actions 環境で処理・保存します。分析データはこの説明サイトには掲載しません。

利用について

本ツールを使用することで、YouTube 利用規約に拘束されることに同意します。利用開始前に、本ツールのプライバシーポリシーを確認してください。
